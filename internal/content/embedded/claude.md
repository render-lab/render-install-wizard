# Render for Claude Code

Claude Code receives Render through the **Render plugin**, which bundles the
agent skills and the hosted MCP server together — no raw config editing needed.

## What gets installed

- **Render plugin** — skills + MCP server delivered as one Claude Code plugin.
- **Render CLI** — installed to `~/.render/bin` and added to your PATH.

## Next steps

1. Restart Claude Code so it loads the Render plugin.
2. On first use, approve the Render MCP OAuth prompt to connect your account.
3. Try: "List my Render services" or "Deploy this repo to Render".

Guide: https://render.com/agents/claude
