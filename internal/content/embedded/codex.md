# Render for Codex

Codex receives Render through the **Render plugin**, which bundles the agent
skills and the hosted MCP server together, so unrelated Codex config is left
untouched.

## What gets installed

- **Render plugin** — skills + MCP server delivered as one bundle.
- **Render CLI** — installed to `~/.render/bin` and added to your PATH.

## Next steps

1. Restart Codex so it loads the Render plugin.
2. Approve the Render MCP OAuth prompt on first use.
3. Try: "Show my Render deploys" or "Create a new web service on Render".

Guide: https://render.com/agents/codex
